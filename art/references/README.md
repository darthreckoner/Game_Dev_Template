# Reference images

The 3–5 images the designer chose before a visual direction was approved. The
art bible names each one and says what to take from it (palette, shapes,
lighting, UI, mood). A direction without references is a suggestion, not a
direction.

Name files by what they show, for example `palette-dusk-town.png`,
`ui-inventory-grid.jpg`. These are study references, not assets: nothing here is
shipped or redistributed. Record where each came from in the art bible's
References section.
