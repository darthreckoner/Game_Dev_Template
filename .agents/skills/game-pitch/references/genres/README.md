# Genre playbooks

One file per genre family, grown from real projects through `$retro`. Each playbook
is short and covers:

- typical core-loop shapes and what makes them satisfying
- known pitfalls, with the project or source that showed each one
- prototype questions that proved decisive, and ones that wasted time
- references worth studying, and what to take from each
- automation hints: what state to assert, which moments to capture

cozy exploration and ship-building; narrative solo RPG.
