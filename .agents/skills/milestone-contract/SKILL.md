# Milestone contract

A contract makes "done" checkable before building starts. Draft it from the
prototype brief and current decisions; the user approves it.

## Procedure

1. Read `PROJECT.md`, the prototype brief's milestone entry, `art/ART_BIBLE.md`,
   and the previous milestone's evidence and retro if any.
2. Copy `references/contract-template.md` to `docs/milestones/M<n>-<slug>.md`
   and fill it. Keep criteria observable: each names how it will be verified.
3. Make every rule claim testable without rendering where possible. Make every
   presentation claim a named review moment the evidence run can capture.
4. Keep scope to the brief. List tempting additions under "Deferred", not criteria.
5. Present the draft with any open choices and wait for the user's approval.
   Record approval (who, date) in the contract.

## Changing an approved contract

Propose the change with its reason. After the user agrees, append a dated entry to
the contract's change log. Evidence already recorded keeps its original criteria.
