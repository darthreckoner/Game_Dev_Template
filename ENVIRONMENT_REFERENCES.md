# Environment references

For environment materials, lighting, foliage detail, distant forests, image
stability or rendering performance, start at the canonical
[Game Dev Library environment index](C:/Dev/Game_Dev_Library/ENVIRONMENT_REFERENCES.md).

The [Far Cry4 source catalog](C:/Dev/Game_Dev_Library/docs/research/2026-10-23-far-cry-4-environment-rendering/README.md)
provides 38 topic IDs and page ranges covering materials, sky/reflections, indirect
lighting, vegetation, antialiasing and performance. Its original PDF and provenance
are preserved in the Library. Read the slide image and speaker notes before
adapting an example. Historical measurements do not establish a project's budget.

Record the chosen adaptation, tradeoff, candidate measurements and designer's
judgment in the game's existing decision format. This pointer adds reference
navigation; it does not select an engine, rendering feature or visual direction.
